# AHHA

**AHHA** — the Andii Hei design system. A personal, multi-brand design system:
a Design Language (Layer 1) expressed as brand token packs, a brand-agnostic
Colour Scheme contract (Layer 2, eight slots), and components that consume
slots, never brands directly.

- Namespace: `ads` (AHHA Design System)
- Package (planned): `@andiihei/ahha`

## Documentation

The design system specimen — colour, schemes, typography, spacing, grid,
elevation, radius, motion, and opacity, plus the AI-readiness strategy and
capture status — is published via GitHub Pages from this repository
(deployed from `main` by GitHub Actions; `index.html` at the repo root).

## Status

Pre-1.0. The system is developed trunk-based in this repository; consuming
projects (portfolio, Career Arcs, and other side projects) pin a released
version and upgrade by deliberate bump.
